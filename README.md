# Job Application Tracker

A responsive job application tracking dashboard that helps users manage job applications, track interview progress, monitor rejected applications, and organize opportunities through an interactive tab-based interface.

##  Live Demo

🔗 Live Site: https://statuesque-salmiakki-676652.netlify.app/

---

## 🚀 Features

###  Dashboard Overview

- Total Jobs counter
- Interview counter
- Rejected counter
- Real-time dashboard updates

### Job Management

Each job card includes:

- Company Name
- Position
- Location
- Employment Type
- Salary Range
- Description
- Current Status

###  Job Status Tracking

- All Jobs tab
- Interview tab
- Rejected tab
- Dynamic filtering by status

###  Status Toggle

- Move jobs to Interview
- Move jobs to Rejected
- Switch between Interview and Rejected status
- Dashboard counts update automatically

###  Delete Functionality

- Remove jobs from the UI
- Dashboard statistics update instantly
- Job counts update automatically

###  Responsive Design

- Mobile Friendly
- Tablet Friendly
- Desktop Optimized
